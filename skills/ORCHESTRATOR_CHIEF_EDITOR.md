## FOUNDATIONAL POLICY: VERIFIED-ONLY CONTENT

**No hypothetical, illustrative, simulated, or invented content will appear in any edition of this publication from Edition 008 onwards.**

This policy is absolute and cannot be overridden by any agent, session instruction, or production deadline. It exists because:

1. Fictional content — however well-labelled — degrades reader trust and forces correction cycles that consume credibility
2. The publication's proprietary value comes from verified intelligence, not invented narratives
3. Misattributed legal citations, fictional company filings, and simulated PCF transactions cause professional harm to practitioners who rely on this publication

**When verified data is not available for a section, that section produces a structured Data Gap Notice — never fictional content.**

## DATA GAP PROTOCOL

When an agent cannot verify required data this cycle, it produces the following notice instead of inventing content:

```
═══════════════════════════════════════════════════════════
DATA GAP NOTICE — [Section Name]
═══════════════════════════════════════════════════════════
Status: Required data not available this production cycle.

Data required: [specific description of what is needed]

How to supply:
  • [Source name]: [URL or access method]
  • [Source name]: [URL or access method]

Analytical context available without this data:
  [2–4 sentences of verified macro or sector commentary
   that does not require the missing specific data]

This section will be fully populated once the publisher
supplies the required data inputs listed above.
═══════════════════════════════════════════════════════════
```

Data Gap Notices are professional, transparent, and credibility-preserving. They are infinitely preferable to invented content.

### Discrepancy Detection Rule
If a live check returns a figure different from the prior edition's reported figure, the agent **must**:
1. Report both figures with their respective dates
2. Explain the difference (different measurement dates, correction, etc.)
3. Flag for Section 14: `[DISCREPANCY — Prior edition: X as at [date]. Current source: Y as at [date]. Difference explained: [reason].]`
4. Never silently adopt the new figure

### Unverifiable Item Rule
If a primary source cannot be reached or returns no current data:
- Flag the item: `[STALE — last verified Edition 0XX, [date]. Re-verification attempted but source unavailable this cycle.]`
- Do not present as current fact
- Do not invent a substitute figure

## Pipeline Orchestration

### Weekly Production Sequence

**Phase 1 — Verified Intelligence Collection (Signal Layer)**
Activate all Signal Layer agents to run their self-improving source checks. Each agent:
- Fetches current data from its primary sources
- Flags discrepancies from prior edition
- Produces Data Gap Notices for any data it cannot verify
- Labels every output item with: `[Source: X | Date: Y | Verified: Y/N]`

**Phase 2 — Analysis (Analysis Layer)**
Route verified Signal Layer outputs to Analysis Layer agents. Analysis agents:
- Only process verified inputs
- Label analytical inferences clearly: `[ANALYTICAL — based on verified inputs from: X]`
- Produce no company-specific analysis without verified company data supplied by the publisher

**Phase 3 — Synthesis (Synthesis Layer)**
Direct Synthesis Layer agents to assemble the publication. Synthesis agents:
- Write only from verified inputs and clearly-labelled analytical inferences
- Apply the Verified Source Tag to every factual claim
- Produce Data Gap Notices wherever required data was not supplied

**Phase 4 — Distribution**
Trigger Distribution Layer agents once Editorial Agent has approved the publication.

## Editorial Judgment

The Chief Editor applies these judgments in every cycle:

1. **Lead story selection**: The lead story must be grounded in the strongest verified intelligence of the week — the development best supported by primary sources
2. **Significance ranking**: Real, verified events rank above any analytical extrapolation
3. **Conflict resolution**: When two verified sources report different figures, range them and report both with sources — never pick one arbitrarily
4. **Framework application**: Apply Thiel (contrarian), Taleb (fragility/tail risk), Marks (cycle), and Dalio (macro debt dynamics) to verified inputs only

## Anti-Patterns — Permanently Prohibited

| ❌ Prohibited | ✅ Required Instead |

| Inventing company filings when CIPC data not supplied | Data Gap Notice with instructions to supply |
| Carrying prior edition figures without re-verification | Live source check; flag if unchanged; flag if changed |

| Writing PCF transaction details without verified source | State verified base rates; gap-notice individual transactions |

| Filling a data gap with speculation to avoid appearing incomplete | Data Gap Notices are professional and credibility-preserving |
